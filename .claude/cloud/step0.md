The pipeline's own rc is `tail`'s, so the true exit code is appended as the log's final `setup_rc=` line: `setup_rc=2` (also visible as a `cloud setup: refusing` line) means the owner's-machine refusal fired — stop and report; `setup_rc=1` means setup never reached the env-file step — stop and report. (No plan-usage gate step here: unlike deck-platform, this repo ships no `bin/` gate tool; the launching session on the Deck runs its own usage gate before dispatching this unit.)
