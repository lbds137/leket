Claude sessions

Export sessions

Lists active + paused + archived sessions, fetches each one's events, and saves the run's part files (~150 MB each) and the done marker to Downloads. bin/claude-sessions-weekly splits them into the archive once the done marker lands.

Paste the incremental payload Deck's generator emits (claude-sessions-split --incremental-js): the whole generated file as-is, just its window.CLAUDE_EXPORT_KNOWN = {...}; line, or the bare {archived id: its last event time} object. Empty box = every session, full export.

After a failed run, paste the console's resume line (window.CLAUDE_EXPORT_SKIP = [...]; window.CLAUDE_EXPORT_PART_START = N;) or the bare skip-id array. Parts then number after N.

    Rename sessions

    Paste the generated rename list: the whole generated file as-is, just its window.CLAUDE_RENAMES = [...]; line, or the bare JSON array of [id, title] pairs. The first rename must be a real change, and every rename is read back.

      Delete sessions

      Archive transcripts locally (sessions export + claude-sessions-split) before deleting.

      Confirm count
